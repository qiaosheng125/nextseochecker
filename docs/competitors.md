# 竞品拆解

## Aiso Next.js SEO Checker

- URL：`https://www.getaiso.com/tools/nextjs-seo-checker`
- 强点：Next.js 专项，覆盖渲染、metadata、性能、图片、结构化数据、可抓取性。
- 影响：不能做更全的 SEO checker。
- 我们差异：上线前检查 + 新手解释 + Codex 修复提示。

## vercel-seo-audit

- URL：`https://yusufhan.dev/projects/vercel-seo-audit`
- 强点：CLI 工具，面向开发者，覆盖 robots、redirect、sitemap、metadata、structured data、Open Graph、security headers。
- 影响：开发者命令行方案已经强。
- 我们差异：网页化、无需安装、适合非专业新手。

## SiteLens

- URL：`https://site.radr.in/`
- 强点：sitemap explorer（站点地图浏览器）和 SEO visualizer。
- 影响：不做 sitemap 可视化。
- 我们差异：只抽样检查硬错误。

## SEOtest / FennecSEO / Indexability tools

- 强点：通用 SEO 和可索引性检查。
- 影响：泛工具竞争强。
- 我们差异：Vercel / Next.js 上线前场景，不做通用 SEO 平台。
