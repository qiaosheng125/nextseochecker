# Vercel SEO Preflight

第二站候选项目：给 Next.js / Vercel 新站做 Google 收录前检查。

- 核心关键词：`Next.js SEO checker`（Next.js SEO 检查器）
- 推荐标题：`Next.js SEO Checker for Vercel Sites`
- 域名：`nextseochecker.com`
- GitHub：`https://github.com/qiaosheng125/nextseochecker`
- 状态：GitHub 已推送；Cloudflare 已激活；待 Vercel 导入和绑定域名

## 定位

不是泛 SEO audit（SEO 审计），而是上线前 preflight（预检）：

- canonical（规范链接）
- redirects（跳转）
- robots.txt（机器人协议文件）
- sitemap.xml（站点地图）
- noindex（禁止索引）
- title / description / H1
- Open Graph 基础标签
- JSON-LD 基础解析
